Проверяем все разрешения для корректной работы приложения в дальнейшем


Добавление предмета
1. Нажмите на кнопку "+" в правом нижнем углу
2. Заполните форму:
  - Имя контакта
  - Важность контакта
  - Дата последнего контакта (в формате ГГГГ-ММ-ДД)
3. Нажмите "Добавить"

Редактирование предмета
1. Нажмите на предмет в списке
2. В диалоге измените нужные поля
3. Нажмите "Сохранить"
   
Удаление предмета
1. Нажмите на иконку корзины справа от предмета
2. Подтвердите удаление в диалоге
